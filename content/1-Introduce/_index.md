**Serverless Function Monitoring** This project focuses on deploying, monitoring, and optimizing an AWS Lambda function to ensure performance and cost efficiency for a serverless system. Through integration with Amazon CloudWatch and Amazon SNS, the project provides an overview of the number of invocations, execution time, errors, cold starts, and operating costs of the Lambda function.

Users will:
- Create and optimize a Lambda function using Python.
- Enable Lambda Insights to analyze cold starts.
- Build a visual CloudWatch Dashboard to monitor performance.
- Set up an email alert system when there is a problem or cost threshold is exceeded.

By applying monitoring and alerting techniques, this project helps users to be proactive in operating serverless services and ensure the stability and continuity of the system in a real environment.
