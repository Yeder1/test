#### Create Lambda
1. Truy cập [AWS Management Console](https://aws.amazon.com/console/) 
   + Tìm **Lambda**
   + Chọn **Lambda**
![Lambda](/images/2.prerequisite/01-openlambda.png)

2. Trong giao diện Lambda
   + Chọn **Functions**
   + Chọn **Create a function**
![Lambda](/images/2.prerequisite/02-createlambda1.png)

2.1 Trong phần Create a function
   + Function name nhập **`MonitoringDemoFunction`**
   + Runtime chọn **Python 3.10**
   + Architecture chọn **x86_64**
   + Ấn **Create function**
![Lambda](/images/2.prerequisite/03-createfunction.png)

3. Thông báo tạo thành công như hình bên dưới.
![Lambda](/images/2.prerequisite/04-success.png)
