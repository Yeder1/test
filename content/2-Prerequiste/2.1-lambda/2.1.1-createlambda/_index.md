#### Create Lambda
1. Go to [AWS Management Console](https://aws.amazon.com/console/)
+ Search **Lambda**
+ Select **Lambda**
![Lambda](/images/2.prerequisite/01-openlambda.png)

2. In the Lambda interface
+ Select **Functions**
+ Select **Create a function**
![Lambda](/images/2.prerequisite/02-createlambda1.png)

2.1 In the Create a function section
+ Function name enter **`MonitoringDemoFunction`**
+ Runtime select **Python 3.10**
+ Architecture select **x86_64**
+ Click **Create function**
![Lambda](/images/2.prerequisite/03-createfunction.png)

3. Successful creation notification as shown below.
![Lambda](/images/2.prerequisite/04-success.png)
