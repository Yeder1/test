### About CloudWatch
- **Amazon CloudWatch** is a performance monitoring and log collection service provided by AWS
- Monitor resources such as EC2, Lambda, RDS, DynamoDB, etc.
- Collect and analyze logs, metrics, and events.
- Alert when problems occur (e.g. abnormally high CPU).
- Build intuitive dashboards to monitor the system in real time.

### Practical applications
- Monitor system errors.
- Measure Lambda function performance.
- Early warning when problems occur.
- Analyze access logs, system errors.
